PC ↔ Samsung

Cette version utilise les mêmes fonctionnalités sur PC et Android. La synchronisation automatique n’est pas encore activée : aucun serveur ni compte en ligne n’est configuré.

Pour transférer tes données : exporte une sauvegarde JSON depuis le premier appareil, envoie-la à l’autre, puis restaure-la. Attention : la restauration remplace les données locales.

Une vraie synchronisation sécurisée nécessitera un hébergement, une authentification et un stockage en ligne.

Données et sauvegarde

Les données sont stockées localement dans ce navigateur sur cet appareil. Une suppression des données du navigateur peut les effacer : exporte régulièrement une sauvegarde.

Sélectionne une sauvegarde pour en consulter le contenu avant restauration.

La restauration remplace les données actuelles uniquement après ta confirmation. Garde toujours une copie de ta sauvegarde précédente.
